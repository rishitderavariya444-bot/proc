# Start here

1. Unzip this folder and open it in Claude Code. It becomes the project folder; the Astro site gets created inside it.
2. Paste this as your first message:

   > Read CLAUDE.md and PROCURO_BUILD_PLAN.md, then do Stage 0. Stop when it's done and show me what changed.

3. After each stage, review the result, then say "Do Stage N." Claude ticks off the plan as it goes, so a new session can always pick up where the last one stopped.
4. When you get any of the facts in `docs/OPEN_ITEMS.md`, paste them in and ask Claude to update the site and tick them off.
